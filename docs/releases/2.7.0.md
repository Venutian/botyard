Watch a bot work as it works: a run now reads like the bot's own transcript, live, on the run's page
and the job's page. Four faults of the map are fixed too. New to Botyard? Start with
[Getting started](https://github.com/Venutian/botyard/blob/main/docs/getting-started.md).

## Which file to take

| System | File |
|---|---|
| Windows 10 or 11 | `Botyard-2.7.0-win-x64.exe` |
| macOS on Apple Silicon (M1 and later) | `Botyard-2.7.0-mac-arm64.dmg` |
| macOS on Intel | `Botyard-2.7.0-mac-x64.dmg` |
| Linux | `Botyard-2.7.0-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Botyard-2.7.0-linux-amd64.deb` |
| Android phone | `Botyard-phone-1.2.0-android-arm64.apk` |

`SHA256SUMS.txt` has the checksum of each file.

Bots run on AI tools you install yourself. The free one needs Node.js and then
`npm install -g opencode-ai`; the app's Setup page shows the others and opens their sign-in.

## These builds are not signed

Nothing here is signed with a paid developer certificate, so each system warns the first time:

- **Windows:** in "Windows protected your PC", press **More info**, then **Run anyway**.
- **macOS:** open Botyard once, then **System Settings → Privacy & Security → Open Anyway**. Or in
  Terminal: `xattr -dr com.apple.quarantine /Applications/Botyard.app`
- **Linux AppImage:** `chmod +x Botyard-2.7.0-linux-x86_64.AppImage`, then run it.
- **Android:** allow your browser or file manager to install unknown apps when it asks. The APK is
  signed with the Android project's public test key, the same in every release, so a newer one
  installs over an older one. It is not from a store.

## What is new

- **A run reads like the bot's own transcript.** A run's page, and a job's page under its runs, show
  what the bot said, its thinking where the tool shows it, and each tool it ran as one line (its name
  and what it was given) that opens to the full input and the result. Errors stand out in red. It reads
  Claude Code, Codex, OpenCode and Gemini alike, and keys and tokens in a run's words are hidden.
- **Live while the run goes.** A running run is read again every few seconds. The feed follows the
  newest step; scroll up to read and it stays where you are, with a button back to the newest step.

## Fixed

- A running run's page said it wrote nothing until the run ended. The engine now reads the end of a
  log as the file stands, so a run is readable from its first step.
- A chat with a bot could not be closed: its close button did nothing. It closes, and Escape closes
  the chat you are typing or reading in before anything else.
- The crew bar along the bottom moved sideways when a chat or a side panel opened. It keeps one place
  at the left edge now, and nothing can scroll the whole page sideways.
- The table of runs squeezed its columns in a narrow panel until names stood one letter a line. A
  narrow table shows each run as two readable lines, and a word is never broken into letters.

## From the source

`studio/`, and start again.
