## Which file to take

| System | File |
|---|---|
| Windows 10 or 11 | `Botyard-2.9.0-win-x64.exe` |
| macOS on Apple Silicon (M1 and later) | `Botyard-2.9.0-mac-arm64.dmg` |
| macOS on Intel | `Botyard-2.9.0-mac-x64.dmg` |
| Linux | `Botyard-2.9.0-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Botyard-2.9.0-linux-amd64.deb` |
| Android phone | `Botyard-phone-1.12.0-android-arm64.apk` |

`SHA256SUMS.txt` has the checksum of each file.

Bots run on AI tools you install yourself. The free one needs Node.js and then
`npm install -g opencode-ai`; the app's Setup page shows the others and opens their sign-in.

## These builds are not signed

Nothing here is signed with a paid developer certificate, so each system warns the first time:

- **Windows:** in "Windows protected your PC", press **More info**, then **Run anyway**.
- **macOS:** open Botyard once, then **System Settings → Privacy & Security → Open Anyway**. Or in
  Terminal: `xattr -dr com.apple.quarantine /Applications/Botyard.app`
- **Linux AppImage:** `chmod +x Botyard-2.9.0-linux-x86_64.AppImage`, then run it.
- **Android:** allow your browser or file manager to install unknown apps when it asks. The APK is
  signed with the Android project's public test key, the same in every release, so a newer one
  installs over an older one. It is not from a store.

## What is new

- **Engram: your notes as a brain.** Point Botyard at any folder of markdown notes, such as an Obsidian
  vault, and the Engram view draws it as a brain: each note a neuron in its area's colour, each area a
  lobe, each `[[link]]` a fibre. Replaced decisions turn grey with a fibre to what replaced them; the newest
  shine. Drag to turn it, search it, scrub the timeline back to any day, click a note to read it, edit it, or
  start a new one. It moves only while it is open and goes back to the yard when left alone. Bots never
  reach it through the page.
- **Notes for the bots, with a privacy line.** The `engram` skill lets bots search and read your work notes
  read-only. Personal folders (life, career, money and notes marked private) are served only to runs of
  Claude, and the free-model bots' settings keep their tools out of those folders.
- **A new icon.** The yard's yellow hex nut on a graphite plate, the same on the phone, the desktop app and
  the page.
- **The crew map is the PC's home.** Who leads, who does what and who tells whom, with lines for each kind of
  message, and one Needs-you number everywhere.
- **Tracks.** The way a job moves (build, check, ruling, merge) is kept as data you can read on the page and
  the phone; the crew's own way is a built-in track.
- **Reviews and marks.** Mark exact places in a bot's work, text or pictures, and send every mark at once;
  answer several waiting questions from the answer tray.
- **PC load levels.** Max, None, Light, Medium, Heavy and Full, on the page and the phone, each saying what
  it lets run.
- **Costs and health.** A job's cost summary in dollars; a "done, not in main" measure; the health check
  says when a notes backup fails.
- **Safer by default.** The engine refuses calls that do not say who is calling; connectors can be given
  read-only; one wake per job; credit-only providers stay off the free list.
