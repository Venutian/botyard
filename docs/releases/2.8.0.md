New to Botyard? Start with
[Getting started](https://github.com/Venutian/botyard/blob/main/docs/getting-started.md).

## Which file to take

| System | File |
|---|---|
| Windows 10 or 11 | `Botyard-2.8.0-win-x64.exe` |
| macOS on Apple Silicon (M1 and later) | `Botyard-2.8.0-mac-arm64.dmg` |
| macOS on Intel | `Botyard-2.8.0-mac-x64.dmg` |
| Linux | `Botyard-2.8.0-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Botyard-2.8.0-linux-amd64.deb` |
| Android phone | `Botyard-phone-1.2.0-android-arm64.apk` |

`SHA256SUMS.txt` has the checksum of each file.

Bots run on AI tools you install yourself. The free one needs Node.js and then
`npm install -g opencode-ai`; the app's Setup page shows the others and opens their sign-in.

## These builds are not signed

Nothing here is signed with a paid developer certificate, so each system warns the first time:

- **Windows:** in "Windows protected your PC", press **More info**, then **Run anyway**.
- **macOS:** open Botyard once, then **System Settings → Privacy & Security → Open Anyway**. Or in
  Terminal: `xattr -dr com.apple.quarantine /Applications/Botyard.app`
- **Linux AppImage:** `chmod +x Botyard-2.8.0-linux-x86_64.AppImage`, then run it.
- **Android:** allow your browser or file manager to install unknown apps when it asks. The APK is
  signed with the Android project's public test key, the same in every release, so a newer one
  installs over an older one. It is not from a store.

## What is new

- **Usage of each AI, one click away.** The Claude and Codex meters in the top bar open a list of
  every AI the crew runs on:
  - **Claude and Codex:** the weekly share used (and Codex's five-hour one), and when each resets.
  - **Gemini:** its tokens, and any model that is used up and set aside until its limit resets.
  - **Each free provider** (OpenCode, OpenRouter, NVIDIA, Cloudflare): its published limit in plain
    words, and each of its models: whether it answers, how much work it usually gives before it stops
    and about how much of that is left, or when a model that is out is usually back. These are learned
    from each model's own history, so they are typical values, not promises.
  - **OpenRouter:** how many of its free requests a day are left on your key.
  - **Every provider:** its new tokens in the last 5 hours, day and week.
- On a narrow window or a phone, the meters fold to a gauge button that opens the same list.
