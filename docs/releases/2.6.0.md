The first Botyard release with installers: a desktop app for Windows, macOS and Linux that carries
Botyard inside it, and the Android phone app as an APK. New to Botyard? Start with
[Getting started](https://github.com/Venutian/botyard/blob/main/docs/getting-started.md).

## Which file to take

| System | File |
|---|---|
| Windows 10 or 11 | `Botyard-2.6.0-win-x64.exe` |
| macOS on Apple Silicon (M1 and later) | `Botyard-2.6.0-mac-arm64.dmg` |
| macOS on Intel | `Botyard-2.6.0-mac-x64.dmg` |
| Linux | `Botyard-2.6.0-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Botyard-2.6.0-linux-amd64.deb` |
| Android phone | `Botyard-phone-1.2.0-android-arm64.apk` |

`SHA256SUMS.txt` has the checksum of each file.

Bots run on AI tools you install yourself. The free one needs Node.js and then
`npm install -g opencode-ai`; the app's Setup page shows the others and opens their sign-in.

## These builds are not signed

Nothing here is signed with a paid developer certificate, so each system warns the first time:

- **Windows:** in "Windows protected your PC", press **More info**, then **Run anyway**.
- **macOS:** open Botyard once, then **System Settings → Privacy & Security → Open Anyway**. Or in
  Terminal: `xattr -dr com.apple.quarantine /Applications/Botyard.app`
- **Linux AppImage:** `chmod +x Botyard-2.6.0-linux-x86_64.AppImage`, then run it.
- **Android:** allow your browser or file manager to install unknown apps when it asks. The APK is
  signed with the Android project's public test key, the same in every release, so a newer one
  installs over an older one. It is not from a store.

## What is new

- **A desktop app that runs Botyard by itself.** Install it and open it: it starts Botyard with the
  Node.js it carries and shows the map. If Botyard is already running on the computer (from
  `npm start` or as a service), it shows that one instead. It finds AI tools installed from a
  terminal, says plainly when Botyard cannot start and why (a port taken by another program, for
  one), and has a button to its log.
- **A first-run guide that ends with a bot answering you.** Two new steps: **Say hello to a bot**,
  the quickest proof that a bot's AI runs on your computer, and **Pair a phone**. Every step checks
  itself and has a short list of what to try when it gets stuck. A missing AI tool is named on the
  steps that need one.
- **Pair a phone from the map.** The guide's last step, or **Settings → Phones and computers**, shows
  a code for the phone's camera and opens the phone's door at once, with no restart.
- **The phone app's first run** has the same new steps.
- **Setup in the desktop app** checks the computer's own Node.js, which the AI tools' installs need,
  rather than the one Botyard brings.
- **Starting from the source with too old a Node.js** now says which version is needed, in place of
  an error from deep inside.

## Fixed

- The first `npm run pair` wrote the phone door's address under names the door never read, so the
  door listened on the computer alone and a phone on the Wi-Fi could not reach it. New pairings write
  the right names, and a door file written the old way is read and corrected.

## From the source

Nothing changes for a yard started with `npm start`: pull, then `npm install` and `npm run build` in
`studio/`, and start again.
