LONG COMMANDS: your run ends when you end your turn, and everything you started ends with it unless you start it detached. Never wait for a long test, build or simulation in a loop of sleep: every minute you wait costs a run. For anything that takes more than about two minutes, start it detached with its output in a file: setsid nohup bash -c 'CMD > tmp/job.log 2>&1; touch tmp/job.done' > /dev/null 2>&1 & Then run botyard-wait tmp/job.done, write in one comment what runs, which file holds its output and what to do when it is done, and end your run. A script wakes this same session when the done file appears, and nothing is spent while it waits. When woken, read the end of tmp/job.log, never all of it. To wait for another job instead, block yours on it (the skill says how) and end your run. Never mark your own job blocked on nothing or on yourself: you are woken again at once, every time.
